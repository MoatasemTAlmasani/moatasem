حين يشتكي مستخدم من انقطاع الإنترنت لا أخمّن. أتحرك من الأسفل إلى الأعلى وأتوقف عند أول خطوة تفشل.

### 1) الكابل والمنفذ

هل الضوء ظاهر؟ هل الـWi-Fi متصل؟ جرّب منفذاً أو كابلاً آخر.

### 2) عنوان الجهاز

هل حصل على IP صحيح؟

```
ipconfig /all
```

### 3) البوابة

```
ping 192.168.1.1
```

إن فشل فالمشكلة داخل الشبكة المحلية.

### 4) عنوان خارجي

```
ping 8.8.8.8
```

إن نجح فالاتصال بالإنترنت سليم.

### 5) DNS

```
nslookup google.com
```

إن نجح ping لـ8.8.8.8 وفشل nslookup فالعطل في DNS.

### 6) المسار

```
tracert 8.8.8.8
```

يبيّن أين ينقطع الطريق (البوابة، الراوتر، مزود الخدمة).

## كيف أفسّر النتيجة؟

| النتيجة | العطل المرجّح |
| --- | --- |
| لا IP أو يبدأ بـ169.254 | DHCP أو الكابل |
| ping للبوابة يفشل | السويتش أو الـVLAN أو الجهاز |
| البوابة تعمل و8.8.8.8 يفشل | الراوتر أو الجدار الناري أو المزود |
| 8.8.8.8 يعمل وnslookup يفشل | إعدادات DNS |

هذا الترتيب يعزل العطل بين الجهاز والشبكة المحلية ومزود الخدمة وDNS قبل أن تلمس أي إعداد.
